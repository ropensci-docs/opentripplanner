# Check the what version of OTP the server is running

Check the what version of OTP the server is running

## Usage

``` r
otp_check_version(otpcon, warn = TRUE)
```

## Arguments

- otpcon:

  otpcon object from otp_connect()

- warn:

  logical, if TRUE will check that OTP version matches contents of
  otpcon
